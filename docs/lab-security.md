# Меры безопасности самого стенда

[← Назад к описанию](../README.md)

- Изолированная сеть; интернет — только временной картой «на горячую».
- Регистрация агентов Wazuh — только по паролю (подставной агент не подключится).
- API Wazuh — только локально; SSH на SIEM — только по ключу, вход root запрещён ([configs/lab-wazuh/10-lab-hardening.conf](../configs/lab-wazuh/10-lab-hardening.conf)).
- Отключён cloud-init, удалены файлы установщика Ubuntu с хешами паролей.
- Служебные учётки ПО не совпадают с именами администраторов (урок с пользователем `wazuh`).
- Хранение алертов — 60 дней (ISM-политика индексов: [configs/lab-wazuh/ism-alert-retention-policy.json](../configs/lab-wazuh/ism-alert-retention-policy.json)).
- Секреты не передаются в командной строке: 4688 с командной строкой и auditd `execve` отправляют аргументы команд в SIEM.
