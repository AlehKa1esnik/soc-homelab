# Что видно и чего не видно

[← Назад к описанию](../README.md)

Проверено на Wazuh 4.14.10 со стандартным набором правил.

| Действие | Что в Wazuh |
|---|---|
| Неверный пароль доменного пользователя на WS01 | 4625 на WS01 (правило 60122) + 4771 `0x18` на DC (60104) — корреляция по пользователю, времени и IP |
| `net user /domain`, `net group "Domain Admins" /domain` | Sysmon 1 → правила 92031/92033/92039 (T1087) |
| Создание и удаление учётки на Linux | journald (5901/5902/5903) + auditd (запись в `/etc/passwd`, `/etc/shadow`; команды `useradd`/`userdel`) |
| `nmap -sV` по веб-серверу | ответы 400 в журнале nginx (31101) |
| SYN-скан `nmap -sS` | **не видно** — нужен сетевой сенсор (Suricata/Zeek) |
| Попытка зарегистрировать подставной агент | **не видно** — отказ пишется только в журнал менеджера |
| 4771 / 4768 / 4776 | отдельных правил в наборе Wazuh нет — будут свои правила |
